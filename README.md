# ViralizeLab

AI-powered content creation tools for social media carousels.

## Features

- **Twitter Carousel Creator** - Create engaging Twitter carousels
- **LinkedIn Visuals** - Professional LinkedIn content
- **Meeting Summary** - Visual meeting summaries
- **Customizable Themes** - Multiple color themes
- **Personalization** - Add your name to carousels
- **Download Functionality** - Export your creations

## How to Use

1. Select a carousel type (Twitter, LinkedIn, or Meeting Summary)
2. Click "Customize" to open the editor
3. Add your name and carousel title
4. Choose a theme
5. Add your content (each line becomes a slide)
6. Preview your carousel
7. Download when ready

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
